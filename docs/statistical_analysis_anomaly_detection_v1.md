# AeroInsight — Statistical Analysis & Anomaly Detection v1

## Scope

This additive stage consumes `KPIAnalysis.trend_rows` produced by the existing deterministic KPI engine. It does not reimplement any KPI formula or query the database directly. The Streamlit page uses the existing tenant-scoped `KPIAnalysisService`, which already enforces `kpi.view` and the authenticated tenant context.

## Detection method

- Ordered daily or monthly KPI trend observations are passed to the analyzer.
- Each observation is compared only with earlier observations, so later periods cannot leak into an earlier baseline.
- Daily: minimum 14 earlier non-null observations, trailing lookback 28.
- Monthly: minimum 6 earlier non-null observations, trailing lookback 6.
- Modified robust Z-score uses median absolute deviation (MAD), with an IQR-based fallback.
- A constant baseline deviation is flagged with an undefined score, never an infinite score.
- Default threshold is absolute robust score >= 3.5.

## Direction labels

- `lower_is_worse`: e.g. service level or answer rate.
- `higher_is_worse`: e.g. AHT, ASA, abandonment rate.
- `two_sided`: e.g. volume measures where unusual can be high or low without assuming bad performance.

Direction affects the severity wording only, not whether a statistical deviation is identified.

## Guardrails

- These are anomaly candidates, not root-cause conclusions.
- No seasonal adjustment, holiday calendar, or causal attribution is included in v1.
- Synthetic data remains labelled synthetic and not production-eligible.
- No SQL is generated by an LLM.
- The page is read-only; no schema or data mutations are performed.
- The central KPI formula definitions remain solely in `src/analytics/kpi_definitions.py`.

## Install

Extract the ZIP into the project root, preserving folders. It adds:

- `src/analytics/statistical_analysis.py`
- `app/pages/10_Statistical_Analysis.py`
- `tests/test_statistical_analysis.py`
- this documentation file

No migration is required. Database target remains `db_airlines` through the existing application settings.

## Test

```powershell
python -m pytest tests/test_statistical_analysis.py -q
python -m pytest -q
```

## Run

```powershell
python -m streamlit run app/main.py
```

Open `10 — Statistical Analysis`.
